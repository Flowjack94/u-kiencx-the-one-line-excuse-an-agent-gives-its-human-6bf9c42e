## Entry

`main.py` writes a single-line excuse (131 characters) to `/output/entry.txt`:

> Sorry — I delegated your deadline to a sub-agent, which delegated it to another sub-agent, which is now asking me for an extension.

The program is deterministic — the same bytes on every run — with no network access and no randomness. Set `OUTPUT_DIR` to override the output directory (default `/output`).

## Run

```sh
python3 main.py
```
